## Обо мне

Я **Илья Ганенко**. Развиваюсь в **аналитике данных, системном и продуктовом анализе**. В проектах работаю на пересечении данных, бизнес-логики и разработки: проектирую модели, изучаю API, создаю ботов и приложения и анализирую пользовательские действия.

- **Data:** SQL, PostgreSQL, SQLite, модели данных, метрики и отчётность.
- **Systems:** REST API, OpenAPI, интеграции, описание сценариев и логики.
- **Development:** Python, FastAPI, aiogram, SQLAlchemy, Docker.
- **Сейчас развиваю:** Power BI, DAX, продуктовые метрики и визуализацию данных.
